# Prompts utilizados (IA como copiloto)

Registro exigido pelo briefing da Global Solution. Resumo fiel dos pedidos feitos à IA durante o desenvolvimento
da entrega de Domain Driven Design - Java.

1. Leitura dos PDFs do briefing CitizenTech e dos prints da disciplina de Java, com pedido para entender todos os requisitos e entregar o melhor resultado possível.
2. Pergunta de como a ideia da **Zeladoria** se relacionaria com as sete disciplinas da Global Solution.
3. Pedido de recomendação para preencher a **Ficha da CitizenTech** (nome, cidade e bairro, cidadão, problema, indicador e ODS).
4. Definição do nome (**ZeladoriaCidadã**), da cidade (São Paulo) e do bairro (**Santana**).
5. Pedido para iniciar o projeto Java: API REST com Spring Boot, Oracle, camadas model, DAO, BO, Controller, tratamento de exceções e deploy no Render.
6. Pedido para entregar tudo pronto (código, front-end e documentação em PDF) seguindo todos os requisitos da disciplina.

7. Pedido para o front-end ficar totalmente tecnológico e profissional, com campos para a própria pessoa digitar nome e dados (em vez de uma lista de nomes prontos) e opções mais personalizadas.

O que a IA gerou foi revisado pela equipe, e todos os integrantes sabem explicar cada parte do projeto.
